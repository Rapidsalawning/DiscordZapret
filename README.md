> [!WARNING]
>
> ### Срабатывания антивирусов
>
> Для работы zapret необходим WinDivert, который перехватывает и фильтрует сетевой трафик. Антивирус может реагировать на него, поскольку подобный инструмент способен использоваться как безопасными, так и вредоносными программами. Сам WinDivert вирусом не является.
>
> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) проекта [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle):**
>
> Некоторые антивирусы относят файлы WinDivert к инструментам повышенного риска или хакерским средствам, после чего удаляют их и отправляют в карантин. В названии обнаружения обычно присутствует `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Добавьте папку zapret в исключения антивируса либо отключите обнаружение PUA (потенциально нежелательных приложений). В Kaspersky, например, есть настройка "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Исключение рекомендуется при точном понимании его настройки; если вы не уверены в своих действиях, отключите обнаружение PUA.

## ⚙️ Настройка и запуск

1. Включите Secure DNS (безопасный DNS):
   - В Chrome включите "Использовать безопасный DNS" и выберите поставщика, отличного от "Поставщик по умолчанию".
   - В Firefox включите "DNS через HTTPS", выберите режим "Персональный", затем "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован.
   - В Windows 11 Secure DNS можно включить непосредственно в настройках системы. [Инструкция](https://remontka.pro/dns-over-https-windows-11/). Для Windows 11 этот способ рекомендуется.
   - Владельцам роутеров Keenetic следует включить в настройках опцию "Транзит запросов". При отключенной опции Secure DNS на компьютере может работать некорректно.

2. Загрузите zip- или rar-архив с [последнего релиза](https://github.com/Rapidsalawning/zapret-discord-youtube/releases/latest).

3. Откройте свойства архива и включите флажок "Разблокировать". Для архивов, открытых через 7-Zip или PeaZip, этот пункт можно пропустить.

4. Извлеките архив в каталог, путь к которому не содержит кириллицу и специальные символы.

5. Запустите подходящий скрипт:
   - Для поиска рабочей стратегии: **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`.
   - Для установки стратегии в автозапуск: **`service.bat`** -> `Install Service` -> выберите нужную стратегию.

## ℹ️ Что делают файлы

- [**`general.bat ...`**](./general.bat) запускает стратегию вручную.

  Такой запуск удобен для проверки стратегий. Результат зависит от множества факторов, поэтому перебирайте разные варианты, включая **ALT**, **FAKE** и другие, пока не найдете подходящий.

- [**`service.bat`**](./service.bat) содержит установку автозапуска и дополнительные операции:
  - <ins>**`Install Service`** добавляет выбранную стратегию в автозапуск через services.msc.</ins>
  - **`Remove Services`** удаляет стратегию и WinDivert из служб.
  - **`Check Status`** показывает состояние обхода, автозапущенной стратегии и WinDivert.
  - **`Game Filter`** меняет режим обхода для игр и других сервисов, работающих с UDP и TCP на портах выше 1023. После изменения необходимо перезапустить стратегию. Текущее состояние указывается в скобках.
  - **`IPSet Filter`** переключает обработку сервисов из `ipset-all.txt`. Это помогает при проверке ресурса, который без zapret работает. Возможные состояния:
    - `none` — IP-адреса не проходят проверку;
    - `loaded` — проверяется принадлежность IP списку;
    - `any` — под фильтр попадает любой IP.
  - **`Auto-Update Check`** включает или выключает автоматическую проверку обновлений.
  - **`Replace active fakes`** заменяет используемый fake на другой файл из каталога `bin`.
  - **`Update IPSet List`** загружает актуальный `ipset-all.txt` из репозитория.
  - **`Update Hosts File`** обновляет hosts-файл <ins>для восстановления веб-версии Telegram и подключения к голосовому чату Discord.</ins>
  - **`Check for Updates`** проверяет наличие обновлений.
  - **`Run Diagnostics`** ищет распространенные причины неисправности zapret. В завершение можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`, что иногда возвращает работоспособность клиента.
  - **`Run Tests`** проверяет стратегии:
    - `Standard tests` — сайты из `utils/targets.txt`;
    - `DPI checkers` — DPI у разных провайдеров, включая Cloudflare и Amazon.

## ☑️ Частые вопросы

### После `general*` ничего не меняется

При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe (обход), видимый на панели задач. Если его нет, обратитесь к [#522](https://github.com/Rapidsalawning/zapret-discord-youtube/issues/522).

### Ни одна стратегия не работает

1. Откройте командную строку от имени администратора.
2. Выполните команды по очереди:

```cmd
netsh winsock reset
netsh int ip reset all
netsh winhttp reset proxy
ipconfig /flushdns
```

3. Перезагрузите компьютер.

### Не открывается Telegram в браузере

В **`service.bat`** выберите **`Update hosts file`**. Если текущий hosts-файл устарел, программа предложит обновить его вручную:

- Скопируйте весь текст из открытого блокнота.
- От имени администратора откройте текстовым редактором файл `hosts` в созданной папке.
- Вставьте скопированное в конец файла `hosts` либо замените ранее добавленный аналогичный блок.
- Сохраните файл и проверьте подключение. Если изменений нет, убедитесь, что hosts действительно был сохранен.

#### Работа не гарантируется

При отсутствии результата используйте [Telegram Desktop](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/Rapidsalawning/tg-ws-proxy) или любым публичным прокси.

### Обход перестал работать

> [!IMPORTANT]
> **Стратегии могут устаревать.** Обнаружение конкретной стратегии со временем приводит к прекращению ее работы. В репозитории есть много вариантов обхода. Если готовые варианты не подходят, создайте новую стратегию на основе одной из них, изменив параметры. Описание параметров находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

Проверьте следующее:

- Запустите `service.bat` -> `Run Diagnostics` и убедитесь, что там нет ошибок.
- Убедитесь, что адрес ресурса присутствует в списках доменов или IP.
- Проверьте другие варианты, включая **`ALT`** и **`FAKE`**.
- Выполните полную переустановку по инструкции ниже.
- Дополнительная информация есть в [#765](https://github.com/Rapidsalawning/zapret-discord-youtube/issues/765).

### Полное обновление или переустановка

- Сохраните добавленные вами ресурсы и данные.
- Перезагрузите устройство.
- Выполните `service.bat` -> `Remove Services`.
- Запустите `service.bat` -> `Run Diagnostics`; исправьте найденные ошибки и в конце выберите Y.
- Удалите старый каталог zapret.
- Скачайте последнюю версию со [страницы релизов](https://github.com/Rapidsalawning/zapret-discord-youtube/releases), архив `zapret-discord-youtube-...`.
- Откройте свойства архива через контекстное меню. Если внизу справа есть флажок разблокировки, включите его, нажмите "Применить", затем "ОК".
- Распакуйте файлы в новый каталог в корне диска, без пробелов, специальных символов и кириллицы.
- Запускайте разные `general`-скрипты и проверяйте доступ к интернет-ресурсам. Если вариант не работает, закройте программу через значок замка на панели задач и попробуйте следующий.
- После выбора рабочей стратегии установите ее в автозапуск: `service.bat` -> `Install Service` -> выберите стратегию.

### Игра или приложение не работает с zapret

В `service.bat` проверьте, что `Game Filter` имеет состояние **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит сообщает о WinDivert

Инструкция находится в репозитории [windivert-hide](https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide).

### Windows 7 требует цифровую подпись драйвера WinDivert

Замените `WinDivert.dll` и `WinDivert64.sys` в [`bin`](./bin) одноименными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### WinDivert остается в службах после удаления через [**`service.bat`**](./service.bat)

1. Узнайте имя службы в командной строке Windows, открытой через Win+R -> `cmd`:

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите службу, подставив имя из первого шага:

```cmd
sc stop название_из_первого_шага
sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8F-настройка-и-запуск).
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Переберите остальные стратегии, особенно если раньше все работало.
- См. [#251](https://github.com/Rapidsalawning/zapret-discord-youtube/discussions/251).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что настроен [Secure DNS](#%EF%B8%8F-настройка-и-запуск).
- Сначала определите стратегию, на которой открывается YouTube, и запустите ее.
- Выполните `service.bat` -> `Run Diagnostics`, затем очистите кэш Discord.
- Проверьте приложение Discord и результат очистки кэша.
- Откройте Discord в браузере по адресу https://discord.com/app. Если веб-версия работает, можно пользоваться ей.
- Если браузерная версия тоже не работает, снова проверьте остальные стратегии: YouTube и Discord могут работать на разных вариантах.
- См. [#252](https://github.com/Rapidsalawning/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/Rapidsalawning/tg-ws-proxy).
- Либо используйте бесплатные MTProto-прокси из интернета.

### Не запускаются игры или нет доступа к ним

Игр много, поэтому проверить и исправить каждую невозможно. Универсальная последовательность:

- через `service.bat` обновите ipset и включите `Game Filter`;
- если это не помогло, дополнительно включите `ipset any`.

Учтите: режим `ipset any` может нарушить открытие многих сайтов. Не держите его включенным постоянно. Определите IP-адреса, используемые игрой, и добавьте их в `ipset-all.txt`.

Если результат не изменился, создайте обсуждение в разделе [Discussions](https://github.com/Rapidsalawning/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Нужной проблемы нет в списке

Создайте обращение [здесь](https://github.com/Rapidsalawning/zapret-discord-youtube/issues).

## 🗒️ Добавление других адресов

Дополнительные ресурсы добавляются в следующие файлы:

- **`list-general-user.txt`** — домены; поддомены учитываются автоматически.
- **`list-exclude-user.txt`** — домены, которые нужно исключить. Это полезно, например, когда сеть указана в `ipset-all.txt`, но отдельный домен из нее фильтровать не следует.
- **`ipset-all.txt`** — IP-адреса и подсети.
- **`ipset-exclude-user.txt`** — IP-адреса и подсети для исключения.

Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.
